Crypto Lab

Hash, encrypt and generate keys in your browser.

Everything runs in your browser. Generated keys appear on screen, so use them for testing only.

Hash

Get the digest of some text, or an HMAC if you add a key. Compare checks Web Crypto against a second, independent implementation.

Algorithm

Encrypt

AES-256-GCM with a key derived from your password (PBKDF2, 210,000 rounds). To decrypt, paste the base64 output back in with the same password.

Keys

Generate a fresh key. Secret keys come as hex and base64, key pairs as PEM (SPKI public, PKCS#8 private).

Key type

Self-test

Checks this browser against published test vectors, encryption round-trips and signature verification.
